# Simple Tetris Game
Simple tetris game rendered in the terminal. All core mechanics are present except the different pieces. I solved the problem I was trying to solve and the addition of different pieces is a trivial change.

## Controls
- *h* - move piece left
- *j* - move piece down
- *k* - rotate piece
- *l* - move piece right

## Building from source
- git clone https://github.com/Anant-raj2/tetris.git
- cd tetris
- cmake -B build
- cmake --build build
